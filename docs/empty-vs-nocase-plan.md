# แผน: คำอธิบาย 0 กับ "-" ตอนกรอก + ช่องที่ยังไม่กรอกแสดง "ว่าง"

สถานะ: **แผน รอผู้ใช้สั่ง "เริ่มได้"** · แก้เฉพาะ `src/Index.html` (การแสดงผล) · ไม่แตะข้อมูลในชีต/การบันทึก/การคำนวณ · ขึ้นลิงก์ทดสอบก่อน แล้วผู้ใช้สั่งขึ้นหลัก

## ปัญหาตอนนี้
- ช่องที่ยังไม่กรอก (ว่าง) แสดง `-` (`resShow`, `prNum`) ซึ่ง**เหมือนกับ "-" ที่แปลว่าเดือนนั้นไม่มีเคส** → แยกไม่ออก
- คำอธิบาย 0 / - มีแค่บรรทัดเล็กใต้ตารางรายเดือนในการ์ดตอนแก้ + tooltip · มุมมองตารางมีแค่ tooltip

## ความหมาย (ไม่เปลี่ยน)
- `0` = ผลเป็นศูนย์จริง (นับในค่าเฉลี่ย/ผลรวม) · `-` = เดือนนั้นไม่มีเคส (ไม่นับ แต่นับว่ากรอกแล้ว) · ว่าง = ยังไม่กรอก

## แก้ (ผู้ใช้เลือก)
1. **ช่องที่ดูอย่างเดียวบนหน้าจอ** (การ์ด + มุมมองตาราง · ผลทั้งปี 5 ปี และรายเดือน): ค่าว่างแสดง **"ว่าง" สีเทาอ่อน** (คลาส `.res-empty`, ตัวเล็กกว่าปกติเล็กน้อย) · ค่า "-" ที่กรอกไว้ยังแสดง `-` ตามเดิม
2. **ช่องกรอก** (ผลทั้งปี/รายเดือน ที่แก้ได้ · การ์ดตอนแก้ + แถวตาราง): ช่องที่ว่างขึ้นตัวอ่อน `placeholder="ว่าง"` (หายเมื่อพิมพ์) · ค่าที่บันทึกไม่เปลี่ยน
3. **ช่องสรุปรายเดือน** (เฉลี่ย/ผลรวม/เดือนล่าสุด) เมื่อไม่มีตัวเลข/ข้อความให้สรุปเลย: บนหน้าจอแสดง **"ว่าง" สีเทาอ่อน** แทน `-`
4. **สรุปรายงาน / Export PDF / Word / PowerPoint / หน้าเอกสาร สรพ.**: ค่าว่าง (และช่องสรุปที่ไม่มีผล) = **ช่องเปล่า** (ไม่พิมพ์คำว่า "ว่าง" ให้กระดาษสะอาด) · `-` ที่กรอกไว้ยังพิมพ์ `-` → กระดาษแยก "ไม่มีเคส" กับ "ยังไม่กรอก" ได้
   - เป้าหมายที่ว่างในรายงาน (`esc(k.target) || '-'`) **ไม่แตะ** (ไม่ใช่ช่องผล)
5. **กล่องคำอธิบาย + ตัวอย่าง** (สีอ่อน เห็นตลอด เฉพาะคนที่กรอกผลได้):
   - การ์ดตอนแก้: แทนบรรทัด `NO_CASE_HINT` ใต้ตารางรายเดือนเดิม
   - มุมมองตาราง: แถบบาง ๆ ใต้แถบเครื่องมือ (`.tbl-toolbar`) แสดงเมื่อมีอย่างน้อย 1 ตัวที่ผู้ใช้กรอกผลได้
   - ข้อความ (ร่าง):
     **0** = ผลเป็นศูนย์จริง (นับในค่าเฉลี่ย) · **-** = เดือนนั้นไม่มีเคส/ไม่มีผู้ป่วยเข้าเกณฑ์ (ไม่นับในค่าเฉลี่ย) · **ว่าง** = ยังไม่กรอก
     ตัวอย่าง: อัตราติดเชื้อ — มีผู้ป่วย 20 ราย ไม่มีใครติดเชื้อ → `0` · เดือนนั้นไม่มีผู้ป่วยเลย → `-`
     + ต่อท้ายสั้น ๆ: พิมพ์ข้อความได้ เช่น A, ดีมาก (ไม่นำไปคำนวณ)
   - tooltip ช่องกรอกรายเดือนเดิม (`NO_CASE_HINT`) คงไว้

## ไม่แตะ / ไม่กระทบ
- ข้อมูลในชีต · `saveKpiEdit`/`saveKpi` · การคำนวณเฉลี่ย/ผลรวม/กราฟ/คะแนน KPI/ดึงปีก่อน
- หน้า 🏅 คะแนน KPI · หน้าติดตามงาน · ระบบสอน (🎓) · ช่องที่ไม่ใช่ผล (เป้าหมาย ผู้รับผิดชอบ ฯลฯ)
- ทำผ่านฟังก์ชันแสดงผลจุดเดียว: `resShow` (หน้าจอ) · `prNum`/`prNumH` (รายงาน) · `calculateMonthlySummary` เพิ่มตัวเลือกบอกว่าเป็นหน้าจอหรือรายงาน (ค่าเริ่มต้น = แบบเดิมสำหรับจุดอื่น)
