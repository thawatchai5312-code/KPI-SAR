# แผน: หน้าต่างตั้งค่าใหญ่ขึ้น · 🔁 ตรวจ/รวมตัวชี้วัดซ้ำ (admin) · เตือนชื่อคล้ายตอนเพิ่มตัวชี้วัด

สถานะ: **แผน รอผู้ใช้สั่ง "เริ่มได้"** · ขึ้นลิงก์ทดสอบก่อน แล้วผู้ใช้สั่งขึ้นหลัก

## 1. หน้าต่าง ⚙️ ตั้งค่า (admin) ใหญ่ขึ้น
- กว้างสูงสุด 900px → **1280px** (95% ของจอ) · ส่วนเนื้อหาสูงสุด 75vh → **85vh**
- จอโทรศัพท์: เต็มจอ
- แก้แค่ขนาด ไม่ย้าย/ไม่จัดกลุ่มปุ่มใหม่

## 2. 🔁 ตรวจตัวชี้วัดซ้ำ (admin — ปุ่มใหม่ใน ⚙️ ตั้งค่า ข้าง 🧹 จัดระเบียบข้อมูล)
ไฟล์ใหม่ `src/Dup.js` · หน้าต่างใหม่ `#modal-dup` · ไม่แตะ 🧹 จัดระเบียบ (รายการรวม 22 คู่เดิมยังอยู่ที่เดิม)

### 2.1 หาคู่ที่น่าจะซ้ำ (`dupScan(token, fy)` — อ่านอย่างเดียว)
- เทียบชื่อหลังตัดเลขข้อ/ช่องว่าง/เครื่องหมาย (`pimpKey_` เดิม) ทุกคู่ในปีงบที่เลือก
  - **ชื่อเหมือนกัน** · **ชื่อคล้ายกัน** (ค่าความคล้าย `hkDice_` ≥ 0.8 — ตัวเดียวกับนำเข้า KPI หัวหน้าหน่วย) · **ชื่อหนึ่งอยู่ในอีกชื่อ** (ยาว ≥ 10 ตัวอักษร)
- จัดเป็นกลุ่ม (A≈B, B≈C → กลุ่มเดียวกัน) เรียง: ชื่อเหมือน+หน่วยเดียวกัน → คล้าย+หน่วยเดียวกัน → อื่น ๆ
- **ชื่อเหมือน/คล้ายแต่คนละหน่วย** (เช่น อัตราพลัดตกหกล้มของแต่ละหอผู้ป่วย — ส่วนใหญ่เป็นของแต่ละหน่วยจริง) **แยกไว้ท้ายรายการ ย่อไว้** (กดกางดู/รวมได้) — ผู้ใช้เลือก
- ตัดคู่ที่ไม่ควรเสนอ: ตัวแม่–ตัวย่อยกัน · คู่ที่ admin เคยกด "ไม่ใช่ตัวซ้ำ"
- ข้อมูลจากชุดทดสอบ (สำเนาเก่า 905 ตัว): ชื่อเหมือน+หน่วยเดียวกัน 22 คู่ · ชื่อเหมือนต่างหน่วย 89 คู่ · ชื่อคล้าย+หน่วยเดียวกัน ~190 คู่ (ปนกับชื่อที่ต่างกันจริง เช่น ต่างแค่ช่วงอายุ/เพศ — **admin ต้องเป็นคนตัดสินทุกกลุ่ม ระบบไม่รวมเอง**)

### 2.2 หน้าต่าง
- เลือกปีงบ → รายการกลุ่ม ทีละกลุ่มแสดงต่อตัว: รหัส · ชื่อ · หน่วยงาน · ผู้รับผิดชอบ · ระดับ · หมวด · เป้าหมาย · ผลที่กรอก (ทั้งปี x/5 · รายเดือน x/12) · มีรายละเอียดไหม · เอกสารแนบ/PDCA/CLT/ชุดคะแนนกี่รายการ · แก้ไขล่าสุด
- ต่อกลุ่ม admin เลือก: **ตัวที่เก็บ** (ค่าเริ่มต้น = ตัวที่ข้อมูลครบกว่า) + ติ๊กตัวที่จะรวมเข้า · หรือ **"ไม่ใช่ตัวซ้ำ"** (จำไว้ ไม่เสนออีก — Script Property `DUP_IGNORE_V1`)
- กด "ดูตัวอย่างก่อนรวม" → แสดงผลหลังรวม + **ช่องที่ขัดกัน** (เช่น ผล ต.ค. 80 กับ 75 → ใช้ของตัวที่เก็บ) → ยืนยัน → รวม
- ช่องค้นหาชื่อในหน้าต่าง + ตัวกรอง "ชื่อเหมือน / คล้าย / คนละหน่วย"

### 2.3 กติการวม (`dupCommit` — ใต้ lock · สำรองชีต (ซ่อน) · `Tidy_Log` · `bumpDataVersion_("*","*")`)
- แถว: ใช้ `tidyMergeRows_` เดิม — ช่องว่างของตัวที่เก็บเติมจากตัวที่รวม (เป้าหมาย ผลทั้งปี ผลรายเดือน รายละเอียด ที่มา) · ระดับ/ผู้รับผิดชอบ/หน่วยงาน/หมวด = รวมกัน · ค่าที่ขัดกัน = ใช้ของตัวที่เก็บ (แจ้งในตัวอย่าง) · ลบแถวตัวที่รวม
- ตัวย่อยของตัวที่ถูกรวม → ย้ายไปอยู่ใต้ตัวที่เก็บ
- **ข้อมูลที่ผูกด้วยรหัส ย้ายตาม** (รหัสเดิม → รหัสที่เก็บ):
  - เอกสารแนบ `KPI_Links` (ไม่ซ้ำลิงก์)
  - เอกสาร สรพ. `SAR_Doc`: PDCA / CLT (`D|โรค|R|รหัส`, `DIM|รหัส`, `S|kpis`) — ตัวที่เก็บมีข้อความแล้ว = คงของตัวที่เก็บ แจ้งว่าชน
  - ชุดคะแนน `KPI_Score` (ผู้รับผิดชอบเดียวกันมีแถวแล้ว = คงของตัวที่เก็บ)
  - การผูกต้นทาง NSO (`NSO_Sync`) — แบบเดียวกับ 🧹 จัดระเบียบ
- ปีงบอื่น (ผู้ใช้เลือก): **ปีที่เลือก + ปีที่ใหม่กว่า** — ปีนั้นมีทั้งสองรหัส = รวมแบบเดียวกัน · มีแต่รหัสที่ถูกรวม = เปลี่ยนรหัสเป็นตัวที่เก็บ · ปีที่เก่ากว่าคงเดิม (ประวัติ)
- รันซ้ำได้ · ตัวที่รวมไปแล้วไม่ขึ้นอีก

## 3. เตือนชื่อคล้ายตอนเพิ่มตัวชี้วัดใหม่ (ทุกคนที่เพิ่มได้)
- ฟอร์ม ➕ เพิ่มตัวชี้วัด: พิมพ์ชื่อแล้ว (รอ ~0.5 วิ) ขึ้นกล่องเตือนใต้ช่องชื่อ
  "⚠️ มีตัวชี้วัดชื่อคล้ายกันในปีงบนี้ N ตัว" + รายชื่อ (ชื่อ · หน่วยงาน · ผู้รับผิดชอบ · ชื่อเหมือน/คล้าย) สูงสุด 5 ตัว (กดดูเพิ่มได้)
- กติกาความคล้ายชุดเดียวกับข้อ 2 (ฝั่งเซิร์ฟเวอร์ `findSimilarKpis` — ข้อ 2/3 ใช้ฟังก์ชันเดียวกัน)
- กดชื่อในรายการ = ปิดฟอร์มแล้วไปที่ตัวนั้น (`goToKpi`) ถ้าผู้ใช้มองเห็นตัวนั้น
- **เตือนอย่างเดียว ไม่บล็อก** · กด "เพิ่ม" ตอนยังมีชื่อคล้าย → ถามยืนยันอีกครั้ง "ยังต้องการเพิ่มเป็นตัวใหม่ใช่ไหม"
- เทียบกับ **ทุกตัวในปีงบนั้น** (ผู้ใช้เลือก — รวมตัวที่ผู้ใช้มองไม่เห็น แต่แสดงแค่ ชื่อ/หน่วยงาน/ผู้รับผิดชอบ; ตัวที่มองไม่เห็นกดไปไม่ได้)
