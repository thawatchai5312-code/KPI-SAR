# แผน: แถบซ้ายหน้าแรกไม่เลื่อน/กางตามเมื่อเลื่อนรายการขวา

สถานะ: **แผน รอผู้ใช้สั่ง "เริ่มได้"** · แก้เฉพาะ `src/Index.html` ส่วน "แถบรายชื่อตัวชี้วัดเลื่อนตามการ์ด" · ขึ้นลิงก์ทดสอบก่อน แล้วผู้ใช้สั่งขึ้นหลัก

## พฤติกรรมตอนนี้ (หน้าแรก ทั้ง 3 มุมมอง รพ. / QA / หน่วยงาน · ทั้งการ์ดและตาราง · เฉพาะจอกว้าง > 1000px)
- เลื่อนรายการขวา (การ์ด/ตาราง) → หยุดเลื่อน 0.15 วิ → `updateTreeInView` เรียก
  - `focusTreeOn` = **กางเฉพาะหมวดของตัวที่อยู่บนจอ ย่อหมวดอื่นทั้งหมด**
  - `scrollTreeTo` = **เลื่อนแถบซ้ายไปหาตัวนั้น**
  - + ไฮไลต์ตัวที่อยู่บนจอ (`.in-view`)
- ผู้ใช้ไม่ได้สั่ง แถบซ้ายจึงกาง/ย่อ/กระโดดเอง → สับสน

## แก้
- **ตัดการกาง/ย่อ/เลื่อนแถบซ้ายอัตโนมัติ** ตอนเลื่อนรายการขวา (ทั้ง 3 มุมมอง การ์ดและตาราง) — แถบซ้ายอยู่ตามที่ผู้ใช้กาง/ย่อ/เลื่อนเอง
- **คงไว้** (ผู้ใช้สั่งเอง):
  - กดชื่อตัวชี้วัดในแถบซ้าย → รายการขวาเลื่อนไปหาตัวนั้น + กะพริบ (`goToKpi`)
  - กดจากหน้าติดตามงาน / ป้าย "ตัวย่อยของ" → ไปที่ตัวนั้น และกางหมวดของตัวนั้นในแถบซ้าย
  - กาง/ย่อหมวดเอง · ปุ่ม "ย่อทั้งหมด"
- **เก็บไฮไลต์ตัวที่อยู่บนจอ** (`.in-view` — เปลี่ยนสีพื้นอย่างเดียว แถบไม่ขยับ; เห็นเมื่อหมวดนั้นกางอยู่) — ผู้ใช้เลือก
- **สลับมุมมอง (รพ./QA/หน่วยงาน) ยังกางหมวดแรกให้เหมือนเดิม** — ผู้ใช้เลือก
- **เข้าสู่ระบบ/โหลดหน้าแรกครั้งแรก/เปลี่ยนปีงบ: กางหมวดแรกให้ 1 ครั้ง** (เดิมได้จากการเลื่อนตาม) หลังจากนั้นไม่ขยับเอง — ผู้ใช้เลือก
- **โหมดการ์ด เปลี่ยนหน้า (1, 2, 3…) / เปลี่ยนจำนวนต่อหน้า: แถบซ้ายไม่ขยับ** (ไฮไลต์ยังอยู่) — ผู้ใช้เลือก
- เปลี่ยนตัวกรอง (ขอบเขต/สถานะ/คำค้น) และอัปเดตอัตโนมัติทุก 10 วิ: คงหมวดที่ผู้ใช้กางไว้ (ไม่กระโดด)
- จอแคบ ≤ 1000px: เดิมไม่เลื่อนตามอยู่แล้ว — ไม่เปลี่ยน
- โค้ดที่ไม่ใช้แล้ว (`treeSyncPaused`, `treeHover`, `treeSyncTimer`, `markTreeBrowsing`, `suppressTreeSyncUntil`) ตัดออกพร้อมทุกจุดที่เรียก (หัวหมวด, ย่อทั้งหมด, `goToKpi`) — ตรวจแล้วไม่มีที่อื่นใช้ · ไฮไลต์ตัวที่เลือก (`.selected`) ไม่แตะ — ตัวนับเวลาเข้าดู (`trackView` ใน `observeCards`) **ไม่แตะ**

## ตรวจแล้วไม่ต้องแก้
- ข้อความระบบสอน (🎓) ไม่ได้พูดถึงการเลื่อนตาม · หน้าสรุปรายงาน/SAR/CLT ไม่มีการเลื่อนตาม

## หน้า 🏅 คะแนน KPI
- ตรวจแล้ว **ไม่มี**การเลื่อนตาม — แถบซ้ายขยับเฉพาะตอนกดชื่อคน/ตัวชี้วัด จึงไม่ต้องแก้

## เทสต์
- `tests/ui25.js` (เดิมทดสอบการเลื่อนตาม) ปรับเป็น: เลื่อนรายการขวา (การ์ดและตาราง) / เปลี่ยนหน้าการ์ด แล้วหมวดที่กาง + ตำแหน่งเลื่อนของแถบซ้าย **ไม่เปลี่ยน** · ไฮไลต์ตัวบนจอยังเปลี่ยนตาม · โหลดหน้าแรก/สลับมุมมองกางหมวดแรก · กดชื่อในแถบซ้ายยังพาไปตัวนั้น · จอแคบเหมือนเดิม
- รันเทสต์หน้าแรกเดิมที่เกี่ยวข้อง (goToKpi / ระบบสอน / ตาราง / การ์ด) ซ้ำ
