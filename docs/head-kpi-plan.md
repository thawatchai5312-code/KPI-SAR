## ส่วน A: ช่องผลรับได้ทั้งตัวเลขและข้อความ (ไม่มีการตั้งชนิด)

ผู้ใช้ขอ (แก้แผน): **ไม่ต้องมีช่องตั้ง "ชนิดผล"** — ทุกตัวชี้วัดกรอกผล (ทั้งปี/รายเดือน) เป็นตัวเลขหรือข้อความก็ได้ ตัดสินจากค่าที่กรอกทีละช่อง
ไม่เพิ่มคอลัมน์ในชีตปีงบ (`KPI_COLS` คงเดิม 39)

### A.1 กติกาค่าในช่องผล (ใช้ทั้งเซิร์ฟเวอร์และหน้าเว็บ)
| ค่าที่กรอก | เก็บเป็น | หมายเหตุ |
|---|---|---|
| ว่าง | ว่าง (ยังไม่กรอก) | เหมือนเดิม |
| `-` | "ไม่มีเคส" (เฉพาะรายเดือน) | เหมือนเดิม · ผลทั้งปี `-` = ว่าง เหมือนเดิม |
| `NA` / `N/A` | พิมพ์ใหม่ในรายเดือน = "ไม่มีเคส" · ค่าเดิมในชีต = ว่าง | เหมือนเดิม (กติกาใน CLAUDE.md) |
| ตัวเลขหลังปรับรูป: เลขไทย→อารบิก, ตัด `,` หลักพัน, ตัด `%` ท้าย, ตัดช่องว่าง (`80%`→80, `1,234`→1234, `๘๐`→80) | **ตัวเลข** | ใช้คำนวณ/กราฟได้ |
| อย่างอื่น (เช่น `A`, `B-`, `ดีมาก`, `ผ่าน`) | **ข้อความ** trim, ยาวไม่เกิน 60 ตัวอักษร | ไม่นำไปคำนวณเฉลี่ย/ผลรวม/กราฟ |

- ฟังก์ชันกลางฝั่งเซิร์ฟเวอร์ `resultValue_(raw, isMonth)` (แปลงค่าที่ส่งมา) และ `readResult_(cell, isMonth)` (อ่านจากชีต) · ฝั่งหน้าเว็บมีฟังก์ชันชื่อเดียวกันแบบเดียวกัน (`resultValue`)
- **ไม่แก้ `cleanValue_` / `cleanMonth_` เดิม** (NSO import ใช้อยู่) — `rowToKpi_` เปลี่ยนไปใช้ `readResult_` สำหรับ G–W เท่านั้น
- ⚠️ ผลข้างเคียงที่ต้องรู้: ค่าข้อความที่มีอยู่แล้วในชีตแต่ตอนนี้ถูกซ่อนเป็น "ว่าง" จะ**กลับมาแสดง** — ข้อมูลทดสอบปีงบ 2569 มีผลรายเดือนเป็นระดับ 5 ช่อง (`A`, `A-`, `B`, `B-`) ซึ่งตรงกับที่ผู้ใช้ต้องการ · ก่อนขึ้นหลักให้รันตรวจแบบอ่านอย่างเดียวว่าในชีตจริงมีข้อความอะไรใน G–W บ้าง (นับ/ตัวอย่าง) แล้วแจ้งผู้ใช้

### A.2 บันทึก (`saveKpiCore_`, `propagateAnnual_`)
- ผลที่ส่งมาผ่าน `resultValue_` (แทน `numberOrNull_`/`monthOrNull_` ในส่วนผล)
- เขียน G–W: ช่องที่เป็นข้อความตั้ง `setNumberFormat("@")` เฉพาะเซลล์นั้นก่อนเขียน (กันชีตแปลง `1/2` เป็นวันที่) · ช่องตัวเลขไม่แตะรูปแบบ
  - เซลล์ที่เคยเป็น `@` แล้วได้ตัวเลข → ชีตเก็บเป็นข้อความตัวเลข → `readResult_` อ่านกลับเป็นตัวเลขได้ (รองรับอยู่ในตาราง A.1)

- สถานะ 3 สี (`periodHasData`): ข้อความนับว่ากรอกแล้ว (เช็ก `!== null` อยู่แล้ว)
- ตารางรายงาน/Export: แสดงข้อความในช่องผล (ช่องแคบ — ข้อความยาวตัดบรรทัดในช่อง ไม่ล้น: ตั้ง `white-space: normal` เฉพาะเซลล์ที่เป็นข้อความ)

## ส่วน B: ระบบคะแนน KPI

### B.1 รูปแบบในไฟล์ต้นทาง (วิเคราะห์แล้ว)
- แต่ละ KPI ของหัวหน้ามี **น้ำหนัก** (1, 2, …) และ **เกณฑ์ 7 ช่อง** ของคะแนน 2.0 / 2.5 / 3.0 / 3.5 / 4.0 / 4.5 / 5.0
- คะแนนรอบ = **กรอกเอง** ในไฟล์ (สูตรมีแค่ `น้ำหนัก × คะแนน`) · ประเมิน 2 รอบ: รอบ 1 ต.ค.–มี.ค. · รอบ 2 เม.ย.–ก.ย.
- น้ำหนัก/เกณฑ์ **เป็นของคู่ (ตัวชี้วัด, หัวหน้า)** — ตัวชี้วัดเดียวกันของหัวหน้าต่างคนอาจมีน้ำหนัก/เกณฑ์ต่างกัน
- เกณฑ์เขียนหลายแบบ: ตัวเลขล้วน (เพิ่มขึ้น = ยิ่งสูงยิ่งดี / ลดลง = ยิ่งต่ำยิ่งดี) · มีเครื่องหมาย (`<75`, `≥76`, `>5`, `≤ 2 %`) · ข้อความ (`มากกว่า 1`, `1 ครั้ง/ปี`) · ค่าหลายตัว (`6,6,6`) · ว่างบางช่อง · บางแถวไม่เรียงลำดับ (พิมพ์ผิด) · บางเซลล์ถูกชีตแปลงเป็นวันที่

### B.2 ที่เก็บ: ชีตใหม่ `KPI_Score` (แยกจากชีตปีงบ แบบ `SAR_Doc`/`KPI_Links`)
คอลัมน์ (ข้อความทั้งหมด `@`): ปีงบ · รหัสตัวชี้วัด · ผู้รับผิดชอบ (ชื่อบัญชี) · น้ำหนัก · เกณฑ์ 2.0 · 2.5 · 3.0 · 3.5 · 4.0 · 4.5 · 5.0 · คะแนนรอบ 1 (กรอกเอง) · คะแนนรอบ 2 (กรอกเอง) · หมายเหตุ · แก้ไขล่าสุดเมื่อ · โดย
- 1 แถว = 1 คู่ (ปีงบ, รหัส, ผู้รับผิดชอบ) · เกณฑ์เก็บ **ข้อความตามที่กรอก** (คำนวณตอนอ่าน)
- ไฟล์ใหม่ `src/Score.js`: `scoreSheet_`, `scoreRead_(fy)`, `getScoreBoard(token, fy, person)`, `saveKpiScore(token, fy, p)`, `deleteKpiScore(token, fy, p)`, `scoreCompute_(kpi, row)`
- ทุกการเขียน: script lock + `baseRev` (แฮชของแถว) + `bumpDataVersion_(fy, [], user, "SCORE")` (`pollChanges` ส่ง `docs` มี `"SCORE"` ให้หน้าเว็บดึงใหม่)

### B.3 การคิดคะแนน (`scoreCompute_` ฝั่งเซิร์ฟเวอร์ที่เดียว หน้าเว็บแค่แสดง)
1. **ผลรอบ** = สรุปผลรายเดือนของรอบนั้นตาม `summaryMethod` ของตัวชี้วัด (รอบ 1 = ต.ค.–มี.ค. ช่อง 0–5, รอบ 2 = เม.ย.–ก.ย. ช่อง 6–11) · ไม่มีผลในรอบ = ยังไม่มีคะแนน
2. **แปลงเกณฑ์** ทีละช่อง → `{op, num}` (`op` จาก ≥ > ≤ < = หรือคำ "มากกว่า/น้อยกว่า/ไม่เกิน/ไม่ต่ำกว่า…" แบบ `pimpTarget_`; ตัด %, "ร้อยละ", หน่วยท้าย) · ช่องว่างข้าม · ค่าหลายตัว/วันที่/อ่านไม่ได้ = ช่องนั้นใช้ไม่ได้
3. **ทิศทาง**: เทียบเลขช่องแรกกับช่องสุดท้ายที่ใช้ได้ (มากขึ้น = ยิ่งสูงยิ่งดี, น้อยลง = ยิ่งต่ำยิ่งดี) · เท่ากัน/มีช่องเดียว = ดูเครื่องหมายเป้าหมายของตัวชี้วัด (≤ < = ยิ่งต่ำยิ่งดี)
4. **คะแนน** = ระดับสูงสุดที่ผ่าน: ช่องที่ไม่มีเครื่องหมาย ใช้ `≥` (ยิ่งสูงยิ่งดี) หรือ `≤` (ยิ่งต่ำยิ่งดี) · มีเครื่องหมายใช้ตามนั้น · ไม่ผ่านช่องใดเลย = **0**
5. ผลรอบที่เป็นข้อความ (ส่วน A): คะแนน = ระดับที่ข้อความเกณฑ์ตรงกับผล (ไม่สนช่องว่าง/ตัวพิมพ์)
6. **คำนวณไม่ได้** (ไม่มีช่องที่ใช้ได้ ช่องไม่เรียงตามทิศ หรือข้อความไม่ตรง) → แสดง ⚠️ "คำนวณไม่ได้ — กรอกคะแนนเอง"
7. **คะแนนกรอกเอง** (รอบ 1/รอบ 2) ถ้ามี **ใช้แทนคะแนนที่คำนวณ** · ค่าที่รับ: 0–5 ขั้นละ 0.5
8. คะแนนถ่วง = น้ำหนัก × คะแนน · รวม = Σ คะแนนถ่วง · เต็ม = Σ (น้ำหนัก × 5) · ร้อยละ = รวม/เต็ม × 100
