# แผน: ผู้รับผิดชอบที่เขียนว่า "หัวหน้า…" = ผู้ใช้ระดับหัวหน้า

สถานะ: **แผน รอผู้ใช้สั่ง "เริ่มได้"** · แก้เฉพาะกติกาตัดสิน "เป็นผู้รับผิดชอบ" · ไม่เขียน/ไม่แก้ข้อมูลในชีต · ขึ้นลิงก์ทดสอบก่อน แล้วผู้ใช้สั่งขึ้นหลัก

## สิ่งที่มีอยู่แล้ว (ก่อนแก้)
- ระบบรู้จักคำ `หัวหน้าหน่วย` (ตรงตัวเท่านั้น) ในช่องผู้รับผิดชอบ → นับ **เฉพาะ Tier head** ที่หน่วยที่ระบุในหน้าตั้งค่าตรงกับช่อง "หน่วยงาน" ของตัวชี้วัด · ช่องหน่วยงานว่าง = ไม่มีใครถูกนับ
- `หัวหน้าตึก` = head ขึ้นไปที่สังกัด NSO ทุกคน · คำอื่น เช่น `หัวหน้างาน` `หัวหน้า` ไม่ถูกนับเป็นใครเลย

## กติกาใหม่ (ผู้ใช้เลือก)
- **คำที่นับ**: ช่องผู้รับผิดชอบ (คั่น `/`) มีคำใดก็ได้ที่ **มีคำว่า "หัวหน้า"** เช่น หัวหน้าหน่วย · หัวหน้าหน่วยงาน · หัวหน้า · หัวหน้างาน · หัวหน้าฝ่าย
  - ยกเว้นคำที่ระบบแปลงเป็นชื่อคนอยู่แล้ว (`OWNER_ALIASES` เช่น หัวหน้าพยาบาล → ชื่อคน) — ใช้ชื่อคนตามเดิม
- **ใครเป็นผู้รับผิดชอบ**: ผู้ใช้ **Tier head และ executive (ผอ./QMR)**
  - ช่อง "หน่วยงาน" ของตัวชี้วัดมีค่า → เฉพาะคนที่หน่วยที่ระบุในหน้าตั้งค่า ตรงกับหน่วยในช่องนั้น
  - ช่อง "หน่วยงาน" ว่าง → ทุกคนใน 2 Tier นี้
  - (ผอ./QMR ส่วนใหญ่ไม่ได้ระบุหน่วย → จะถูกนับเฉพาะตัวที่ช่องหน่วยงานว่าง)
- `หัวหน้าตึก`: กติกาเดิม (head ขึ้นไปที่สังกัด NSO) **ยังอยู่** + ได้กติกาใหม่เพิ่ม (หัวหน้าของหน่วยในช่องหน่วยงาน)
- admin ไม่เปลี่ยน (เห็น/แก้ทุกอย่างอยู่แล้ว) · staff ไม่เกี่ยว
- ตัดสินตอนอ่านที่ `getKpiPermission_` จุดเดียว — ไม่เปลี่ยนข้อความในชีต ไม่มี migration

## ผลที่ตามมา (อัตโนมัติ เพราะทุกจุดใช้ `getKpiPermission_`)
- หน้าแรก: ตัวชี้วัดนั้นอยู่ใน "ของฉัน" ของหัวหน้าที่เข้าเกณฑ์ และกรอก/แก้ได้ (สิทธิ์เท่าผู้รับผิดชอบปกติ)
- หน้าติดตามงาน · สรุปรายงาน "👤 KPI รายบุคคล" · น้องเป้า (เห็นตามที่ผู้ใช้เห็น)
- 🏅 คะแนน KPI: เลือกตัวชี้วัดนั้นเข้าชุดคะแนนของหัวหน้าที่เข้าเกณฑ์ได้ · แถวคะแนนเดิมไม่ขึ้น "ไม่ได้เป็นผู้รับผิดชอบแล้ว"

## จุดเล็กที่แก้เพิ่มเพื่อกันผลข้างเคียง
- สร้างบัญชีอัตโนมัติจากผู้รับผิดชอบ (`buildAccountsFromOwners_`): ข้ามคำที่มี "หัวหน้า" (ไม่สร้างบัญชีชื่อ "หัวหน้างาน" ฯลฯ)
- รวมแถว (`tidyMergeRows_` — ใช้ใน 🔁 รวมตัวชี้วัดซ้ำ): คงคำ "หัวหน้า…" ในช่องผู้รับผิดชอบไว้ (เดิมรวมแล้วคำนี้หายไป)

## ไม่แตะ / ไม่กระทบ
- ข้อมูลในชีตทุกชีต · `parseOwners_` (ตัวแยกชื่อคน ใช้หลายที่ — ไม่แก้) · หน่วยงานอัตโนมัติของผู้ใช้ (`ownedDepts_`) → การมองเห็นตัวชี้วัดอื่นไม่เปลี่ยน
- ตัวชี้วัดที่ช่องผู้รับผิดชอบไม่มีคำว่า "หัวหน้า" — ทุกอย่างเหมือนเดิม
- ข้อสังเกต (ไม่แก้รอบนี้): ซิงค์ NSO เขียนช่องผู้รับผิดชอบใหม่จากชื่อคน — คำ "หัวหน้า…" ในตัวชี้วัด NSO อาจหายเมื่อซิงค์ (เป็นแบบนี้อยู่เดิม)

## ข้อควรรู้
- ตัวชี้วัด 1 ตัว = ผลชุดเดียว: หัวหน้าหลายคนกรอก/แก้ **แถวเดียวกัน** (ถ้าต้องการผลแยกต่อคน ต้องเป็นตัวชี้วัดแยกต่อคน)

## เทสต์
- `tests/headown1.js` (เซิร์ฟเวอร์): คำต่าง ๆ ที่มี "หัวหน้า" · หน่วยตรง/ไม่ตรง/ช่องหน่วยงานว่าง · head + executive นับ · staff/ admin ไม่เปลี่ยน · ชื่อคนร่วมในช่องเดียวกันยังเป็นผู้รับผิดชอบ · คำที่เป็น alias ชื่อคน · `หัวหน้าตึก` กติกาเดิมยังใช้ · หน่วยอัตโนมัติไม่เปลี่ยน · `getScoreCandidates` / `getKpisOfPerson` เห็นตัวนั้น · ไม่สร้างบัญชีชื่อ "หัวหน้า…" · รวมแถวคงคำนี้
- รันเทสต์ฝั่งเซิร์ฟเวอร์ทั้งชุด + เทสต์หน้าเว็บที่เกี่ยวกับสิทธิ์/ของฉัน เพื่อยืนยันว่าไม่กระทบส่วนอื่น
