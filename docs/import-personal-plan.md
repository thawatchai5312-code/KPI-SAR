### 2.3 กติกาแปลงข้อมูล
- **ชื่อตัวชี้วัด**: ตัดเลขข้อนำหน้า `^\s*\d+(\.\d+)*\s*[.)]?\s+` · ยุบช่องว่างซ้อน · `arabicDigits_`
- **ชื่อผู้รับผิดชอบ**: ตัดคำนำหน้า (นางสาว, น.ส., นาง, นาย, ว่าที่ร.ต./ว่าที่ ร.ต., ด.ต., ส.ต.อ. ฯลฯ — ทำเป็นรายการคงที่) → แยกด้วยช่องว่าง → `first` = คำแรก, `lastInitial` = อักษรแรกของคำถัดไป · ชื่อเต็มใช้แสดงในหน้าตัวอย่างเท่านั้น ไม่บันทึกที่ไหน
- **หน่วยงาน**: trim ตามไฟล์ (ไม่แปลง alias ยกเว้นผ่าน `renameUnit_` เพื่อไม่ย้อนชื่อที่เปลี่ยนแล้ว)
- **เป้าหมาย** → รูปแบบระบบ `<เครื่องหมาย> <ตัวเลข>` (เครื่องหมาย ≥ ≤ > < =) ตัด "%" / "ร้อยละ" / "ครั้ง":
  | ในไฟล์ (ตัวอย่างรูปแบบ) | แปลงเป็น | หมายเหตุ |
  |---|---|---|
  | `100` / `1` (ตัวเลขล้วน) | `≥ 100` / ⚠️ | ตัวเลขล้วน = ≥ ยกเว้น 0 หรือ 1 ที่กำกวม → ⚠️ ให้ admin ยืนยัน |
  | `≥ 95%` · `≥ 98%` · `>98%` · `< 2%` · `< 0.5%` | `≥ 95` · `≥ 98` · `> 98` · `< 2` · `< 0.5` | |
  | `≥ ร้อยละ 90 ขึ้นไป` · `ร้อยละ 95 ขึ้นไป` · `ไม่ต่ำกว่าร้อยละ 95` · `ไม่น้อยกว่า 3 เรื่อง…` | `≥ 90` · `≥ 95` · `≥ 95` · `≥ 3` | คำ "ขึ้นไป/ไม่ต่ำกว่า/ไม่น้อยกว่า" = ≥ · "ไม่เกิน" = ≤ · "น้อยกว่า" = < |
  | `≥ 95% ของวันเปิดทำการ…` · `บุคลากรทุกคนรายงาน…อย่างน้อย 3 เรื่อง… (100%)` | `≥ 95` · ⚠️ | ข้อความยาว → ต่อท้ายที่มา/สูตร · มีตัวเลขหลายตัว = ⚠️ |
  | `≥ 85% - 95% ขึ้นไป` (ช่วง) · `0 ครั้ง (หรือ น้อยกว่า 2 ครั้งต่อเดือน` · `เป็น 0% หรือ 0 ครั้ง…` · `<` (ไม่มีเลข) | ⚠️ | กำกวม → เสนอค่าที่เดาได้ (เช่น `= 0`) แต่ติด ⚠️ ให้ admin ยืนยัน/แก้ |
  | ว่าง | ว่าง | ติด ⓘ "ไม่มีเป้าหมายในไฟล์" (นำเข้าได้) |
  ทำเป็นฟังก์ชัน `pimpTarget_(text) → { value, original, sure: bool, note }` มีเทสต์ครอบทุกแบบในตารางนี้
- **ผลรายเดือน** (ถ้ามี): ตัวเลข / "-" ใช้กติกาเดียวกับระบบ (`monthOrNull_`) — ไฟล์นี้ไม่มี

### 2.4 ฝั่งเซิร์ฟเวอร์ (ไฟล์ใหม่ `src/PersonalImport.js`)
- `personalImportPreview(token, url)` — admin เท่านั้น (`requireAdmin_`) · อ่านชีตแรกของไฟล์ · หาแถวหัวตารางจากชื่อคอลัมน์ (`ตัวชี้วัด`, `เป้าหมาย`, `KPI Template`, `หน่วยงาน`, เดือน) ไม่ fix เลขคอลัมน์ · คืน:
  `{ fy, people: [{ key, fullName, first, suggested, existing: {username, tier, depts} | null, choice: "new"|"existing", newName }], rows: [{ i, personKey, name, target: {value, original, sure, note}, unit, template, months, dup: "same"|"similar"|null, dupId }], newUnits: [...], stats }`
  - `dup = "same"`: ปีงบนั้นมีตัวชี้วัดชื่อเดียวกัน (หลังตัดเลข/ช่องว่าง) **และ**ผู้รับผิดชอบเดียวกันอยู่แล้ว → ข้ามอัตโนมัติ (รันซ้ำได้ ไม่เกิดซ้ำ)
  - `dup = "similar"`: ชื่อตรงแต่ผู้รับผิดชอบต่าง → แสดงเตือน (ยังนำเข้าได้)
  - ไม่เขียนอะไรเลย
- `personalImportCommit(token, url, decisions)` — `decisions = { people: {key: {choice, newName}}, targets: {i: "≥ 95"}, skip: [i…] }`
  1. `requireAdmin_` · `LockService` script lock (รอ 30 วิ) · อ่านไฟล์ + ทำ preview ซ้ำฝั่งเซิร์ฟเวอร์ (ไม่เชื่อ rows จากหน้าเว็บ — รับแค่การตัดสินใจ) · ตรวจ `newName` ห้ามชน/ห้ามว่าง/ห้ามมีช่องว่าง
  2. **สำรองก่อนเขียน**: copy ชีตปีงบ + ชีต Users เป็นชีตซ่อน "<ชื่อ> (สำรองก่อนนำเข้ารายบุคคล <วันเวลา>)" (ดูแบบที่ `Tidy.js`/`Rename.js` ทำ)
  3. สร้างบัญชีใหม่ (staff, รหัสตั้งต้น, mustChange) ด้วย helper เดิมของ Users (อ่าน/เขียนผ่าน `readUsers_` และฟังก์ชันเขียน Users ที่มีอยู่ — ห้ามเขียนรหัสผ่านเป็นข้อความ)
  4. เพิ่มตัวชี้วัดทีละแถวด้วย **ตรรกะเดียวกับ `addIndicator`** (รหัสใหม่ · หมวดอัตโนมัติตามระดับ/หน่วย · ตราประทับผู้สร้าง ฯลฯ) — ถ้า `addIndicator` เขียนรวมในฟังก์ชันเดียว ให้แยกแกนเป็น `addIndicatorCore_(user, fy, item)` (ไม่ตรวจ token ไม่ล็อกเอง) **โดยพฤติกรรมเดิมไม่เปลี่ยน** แล้วให้ `addIndicator` เรียกแกนนี้ (ตรวจด้วยเทสต์เดิมที่ใช้ `addIndicator` เช่น `fwd1`, `t5`/`t13` — ค้นด้วย `grep -l addIndicator tests/*.js`) · ไม่ส่งต่อปีถัดไป (`forward` ไม่ติ๊ก)
  5. จด `Tidy_Log` (ชนิด "personal-import": จำนวนบัญชีใหม่ จำนวนตัวชี้วัด รหัสที่สร้าง)
  6. `bumpDataVersion_(fy, "*", user)` + บอกให้รีเฟรชรายชื่อผู้ใช้ (การแก้ Users ทำให้ `pollChanges` ส่ง full อยู่แล้ว — ตรวจให้แน่)
  7. คืน `{ success, created: n, skipped: n, accounts: [{username}], ids: [...] }`
  - ทั้งหมดต้องเสร็จในเวลาไม่เกินข้อจำกัด Apps Script (6 นาที) — อ่านชีตปีงบครั้งเดียว เขียนแถวใหม่แบบ batch (`setValues` ทีละหลายแถว) ไม่ใช่ `appendRow` 78 ครั้ง
- ตรวจ URL: ต้องเป็น `https://docs.google.com/spreadsheets/` · เปิดไม่ได้ → แจ้งไทย "เปิดไฟล์ไม่ได้ — แปลงเป็น Google ชีตและแชร์ให้บัญชีเจ้าของสคริปต์แล้วหรือยัง" · ถ้าเป็น .xlsx ที่ยังไม่แปลง (`openByUrl` ล้ม) แจ้งวิธีแปลง

### 2.5 หน้าเว็บ (`src/Index.html`)
- `openPersonalImport()` เปิดหน้าต่าง `#modal-pimp`:
  1. ช่องวางลิงก์ Google Sheet + คำอธิบายสั้นวิธีแปลงไฟล์ Excel + ปุ่ม "🔍 ตรวจไฟล์" (ปีงบแสดงเป็นข้อความ "นำเข้าเข้าปีงบ 2570")
  2. ผลตรวจ: สรุปตัวเลข (คน / ตัวชี้วัดใหม่ / ข้ามเพราะมีแล้ว / บัญชีใหม่ / หน่วยใหม่ เช่น จ่ายกลาง ซักฟอก / เป้าหมายที่ต้องตรวจ ⚠️)

  5. ปุ่ม "นำเข้า N ตัวชี้วัด + สร้าง M บัญชี" → ยืนยันซ้ำ (showConfirm) → commit → แจ้งผล + รายชื่อบัญชีใหม่ "รหัสผ่านตั้งต้น 11038 ต้องเปลี่ยนตอนเข้าครั้งแรก" + รีโหลดข้อมูล (`fetchAllDataFromServer`) และรายชื่อ dropdown (`acLoad`)
