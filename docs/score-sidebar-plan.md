# แผน: หน้า 🏅 คะแนน KPI — สิทธิ์เข้า + แถบนำทางซ้ายแบ่งตามคน

สถานะ: **แผน รอผู้ใช้สั่ง "เริ่มได้"** · แก้เฉพาะหน้า/ไฟล์คะแนน (`src/Score.js`, ส่วน "คะแนน KPI" ใน `src/Index.html`) · ขึ้นลิงก์ทดสอบก่อน แล้วผู้ใช้สั่งขึ้นหลัก

## 1. สิทธิ์เข้าหน้า (แก้จากเดิม)
| Tier | เดิม | ใหม่ |
|---|---|---|
| staff | เห็นเมนูเมื่อมีชุดคะแนนของตัวเอง | **ไม่เห็นเมนู · เซิร์ฟเวอร์ปฏิเสธ** |
| head | เห็นของตัวเอง | เห็นของตัวเองเท่านั้น (เหมือนเดิม) |
| executive (ผอ./QMR) · admin | เห็นทุกคน + แก้ได้ | เหมือนเดิม |

- เซิร์ฟเวอร์: `getScoreBoard` / `getScoreCandidates` คืน `success:false` "เฉพาะหัวหน้าหน่วยขึ้นไป" เมื่อ tier = staff · `scoreMeta` ของ staff = ไม่มีสิทธิ์
- หน้าเว็บ: `scoreCanUse()` = `tier !== 'staff'` (ตัดเงื่อนไข "staff ที่มีชุดคะแนน")

## 2. แถบนำทางซ้าย (เหมือนหน้าแรก)
- โครงหน้า: กริดเดียวกับหน้าแรก **22fr : 78fr** (`.home-grid`) · แถบซ้ายเป็น `.panel` sticky + เลื่อนในตัว เหมือน `#panel-tree` · จอ ≤ 1000px ซ้อนบน-ล่าง + ปุ่มพับแบบหน้าสรุปรายงาน
- **หัวข้อใหญ่ = หน่วยงาน** (แบบ Part ในหน้าแรก) · ใต้หน่วย = **ชื่อคน + จำนวน KPI** (ตามที่ผู้ใช้เลือก — ไม่แสดงคะแนน)
  - หน่วยของคน = หน่วยแรกของบัญชี (`depts[0]`) · ไม่มี = "ไม่ระบุหน่วยงาน" · เรียงหน่วยและชื่อตามตัวอักษร
- **กดชื่อคน** = ตารางคะแนนของคนนั้นทางขวา + กางรายชื่อ KPI ของคนนั้นใต้ชื่อ (คนที่เลือกอยู่ไฮไลต์)
- **กด KPI ในแถบซ้าย** = เลื่อนไปแถวนั้นในตาราง + กะพริบแถว
- ช่องค้นหาชื่อคน (กรองรายการทันที) บนสุดของแถบ
- admin/ผอ./QMR: ช่อง "➕ เปิดชุดคะแนนของ…" (พิมพ์/เลือกชื่อบัญชี) ย้ายจากแถบบนของตารางมาไว้ในแถบซ้าย — สำหรับคนที่ยังไม่มีชุดคะแนน
- head: แถบซ้ายมีแค่หน่วย + ชื่อตัวเอง (กางไว้)
- จำว่ากางหน่วยไหนไว้ระหว่างใช้งาน (ไม่จำข้ามการล็อกอิน)

## 3. ข้อมูลจากเซิร์ฟเวอร์
- `getScoreBoard` ส่ง `dir` เพิ่ม (โหลดครั้งเดียวพร้อมตาราง ไม่เพิ่มรอบเรียก):
  `dir: [{ unit, people: [{ person, count, kpis: [{ id, name }] }] }]`
  - admin/ผอ./QMR = ทุกคนที่มีชุดคะแนนในปีงบนั้น · head = ตัวเอง
  - นับเฉพาะแถวที่ยังใช้งาน (ไม่นับแถว stale)
- อัปเดตอัตโนมัติ: เอกสาร `SCORE` เปลี่ยน → โหลดตาราง + `dir` ใหม่ (ไม่วาดทับระหว่างโหมดแก้ไข เหมือนเดิม)
