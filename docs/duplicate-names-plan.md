# แผน: ชื่อผู้ใช้ซ้ำ (ชื่อต้นเหมือนกัน) — ใช้ "ชื่อ นามสกุล"

สถานะ: **วางแผน รอผู้ใช้สั่ง "เริ่มได้"** · ตัวอย่างในไฟล์นี้ใช้ชื่อสมมติ (repo เป็น public — ห้ามใส่ชื่อจริง)

## หลักการ (ผู้ใช้ตัดสินใจแล้ว)

- ไม่เพิ่มคอลัมน์ ไม่แยก "ชื่อเข้าระบบ" กับ "ชื่อในตัวชี้วัด" — ชื่อผู้ใช้ = ชื่อในช่องผู้รับผิดชอบ เหมือนเดิม
- คนที่ชื่อต้นซ้ำกับคนอื่น ใช้ **"ชื่อ นามสกุล"** (เว้นวรรค 1 ช่อง) ทั้งตอนล็อกอินและในช่องผู้รับผิดชอบ
- คนที่ชื่อไม่ซ้ำ ใช้ชื่อต้นเหมือนเดิม (บัญชีอื่นไม่กระทบ)
- พิมพ์แค่ชื่อต้นที่ซ้ำ (ไม่มีนามสกุล) → ระบบเด้งรายการนามสกุลให้เลือก ทั้งตอนล็อกอินและตอนกรอกผู้รับผิดชอบ

นิยาม: **ชื่อกำกวม** = ข้อความ `n` ที่ไม่มีบัญชีชื่อ `n` ตรงๆ แต่มีบัญชีชื่อ `n <นามสกุล>` ≥ 1 บัญชี
(ฟังก์ชันกลาง `ambiguousName_(n, users)` → รายชื่อบัญชีที่ขึ้นต้น `n + " "`)

## ขั้น 1 — เปลี่ยนชื่อบัญชี (admin) ✏️ แท็บใหม่ "ผู้ใช้" ในหน้าต่าง ✏️ เปลี่ยนชื่อ

ตัวอย่าง: `มานี` → `มานี ใจดี` · `มานีร.` → `มานี รักงาน`

- ดูตัวอย่างก่อนเขียน (`renameUserPreview`): จำนวนตัวชี้วัดที่ผู้รับผิดชอบมีชื่อนี้ แยกตามปีงบ
- เขียน (`renameUserCommit`) ใต้ script lock + สำรองชีตปีงบที่แก้ + ชีต Users (ซ่อน) + `Tidy_Log` + `bumpDataVersion_("*","*")`
- สิ่งที่เปลี่ยน:
  - ชีต Users คอลัมน์ A (รหัสผ่าน/Tier/หน่วยคงเดิม)
  - ช่องผู้รับผิดชอบ (Z) **ทุกปีงบ** — เปลี่ยนเฉพาะชื่อที่ตรงทั้งคำ (คั่น `/`) ไม่แตะ "หัวหน้าหน่วย"/"หัวหน้าตึก"/ชื่ออื่น
  - Script Properties ที่ผูกชื่อ: `TOUR_HIDE_V1:<ชื่อ>`, `REPORT_PREFS_V1:<ชื่อ>` ย้ายไปชื่อใหม่
  - session เดิมของบัญชีนั้นใช้ไม่ได้ ต้องล็อกอินใหม่
- **ไม่เปลี่ยน** (เป็นประวัติ): แก้ไขล่าสุดโดย/เข้าดูล่าสุดโดย (AD–AG), `SAR_Doc`, `KPI_Links`, `Tidy_Log`
- ชื่อใหม่ห้ามซ้ำบัญชีที่มี · ห้ามเปลี่ยนชื่อตัวเองขณะล็อกอิน (กันหลุด) หรืออนุญาตแต่บังคับล็อกอินใหม่

## ขั้น 2 — ล็อกอินด้วยชื่อต้นที่กำกวม

- `authenticateUser`: ไม่พบชื่อตรงๆ แต่ชื่อกำกวม → ตรวจรหัสผ่านกับบัญชีที่ขึ้นต้นด้วยชื่อนั้น
  - รหัสผ่านตรง 1 บัญชี → เข้าระบบเลย
  - ตรงหลายบัญชี (เช่น ยังใช้รหัสตั้งต้นทั้งคู่) → คืน `{ choose: [นามสกุล…] }` หน้าเว็บเด้งให้เลือก แล้วล็อกอินด้วยชื่อเต็ม
  - ไม่ตรงเลย → "ชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง" (ไม่เปิดเผยนามสกุลให้คนที่ไม่รู้รหัสผ่าน)
- นับครั้งผิด (`fail_<ชื่อ>`) ตามชื่อที่พิมพ์ เหมือนเดิม
- (ทางเลือก ถ้าผู้ใช้ต้องการ: เด้งนามสกุลก่อนกรอกรหัสผ่าน — เปิดเผยชื่อเต็มให้ทุกคนที่เปิดลิงก์)

## ขั้น 3 — ช่องผู้รับผิดชอบ (การ์ด / แถวตาราง / ฟอร์มเพิ่ม)

- dropdown ค้นหา (`acShow`) แสดงชื่อเต็มอยู่แล้วเมื่อพิมพ์ชื่อต้น — ไม่ต้องแก้
- กดบันทึก (`saveKpiEdit` / ฟอร์มเพิ่ม): มีชื่อกำกวมในช่อง → หน้าต่างเลือกนามสกุล (ทีละชื่อ) แทนที่ชื่อในช่อง แล้วบันทึกต่อ
  รายชื่อบัญชีมาจาก `getDirectory` (โหลดอยู่แล้ว)
- เซิร์ฟเวอร์กันซ้ำ (`saveKpiCore_`, `buildNewKpiRow_`): ช่องผู้รับผิดชอบที่ **เปลี่ยน** แล้วมีชื่อกำกวม → ไม่บันทึก แจ้ง "ชื่อ … มีหลายคน ระบุนามสกุล"
  (ข้อความเดิมที่ไม่ได้แก้ ไม่ตรวจ — กันบันทึกผลรายเดือนไม่ได้)
- ส่งต่อปีถัดไป (`Forward.js`) ใช้ `saveKpiCore_` จึงได้กติกาเดียวกัน

## ขั้น 4 — เส้นทางอื่นที่เขียน/อ่านชื่อผู้รับผิดชอบ

- `buildAccountsFromOwners_` (สร้างบัญชีจากผู้รับผิดชอบ): ชื่อกำกวม → **ไม่สร้างบัญชีใหม่** (ไม่งั้นได้บัญชีชื่อต้นกลับมา)
- 🧹 จัดระเบียบ: รายงานตัวชี้วัดที่ผู้รับผิดชอบเป็นชื่อกำกวม (ไม่แก้เอง)
- นำเข้า NSO: ชื่อจากต้นทางที่กำกวม → เขียนตามต้นทาง + แจ้งในหน้าตัวอย่างให้ admin แก้เอง
- นำเข้ารายบุคคล: ชื่อต้นชนกับบัญชีเดิม + เลือก "สร้างบัญชีใหม่" → ชื่อบัญชี = **"ชื่อ นามสกุล"** (แทน "ชื่อ+อักษรแรก.")
  และแจ้งว่าบัญชีเดิมควรเปลี่ยนเป็นชื่อ นามสกุลด้วย (ขั้น 1)
- KPI รายบุคคล (สรุปรายงาน 👤): ใช้ชื่อเต็มจาก dropdown อยู่แล้ว — ไม่ต้องแก้

## ขั้น 5 — เทสต์ (ข้อมูลสมมติ) + ลิงก์ทดสอบ

- `tests/uname1.js` (เซิร์ฟเวอร์): เปลี่ยนชื่อ (Users + ผู้รับผิดชอบทุกปี + ไม่แตะชื่ออื่น/ตำแหน่ง + prefs + สำรอง/log/bump) · ล็อกอินชื่อกำกวม 3 กรณี · บันทึกชื่อกำกวมถูกปฏิเสธ · สร้างบัญชีจากผู้รับผิดชอบไม่สร้างชื่อต้น
- `tests/ui69.js` (หน้าเว็บ): แท็บผู้ใช้ใน ✏️ · หน้าต่างเลือกนามสกุลตอนล็อกอิน · ตอนบันทึกการ์ด/แถวตาราง/ฟอร์มเพิ่ม
- รันเทสต์ที่เกี่ยว (perm2 t5 fwd1 pimp1 rename* ui27 …) → ลิงก์ทดสอบ → รอ "ขึ้นหลัก"

## หลังขึ้นหลัก (admin ทำในระบบ)

ใช้ ✏️ → แท็บผู้ใช้ เปลี่ยน 2 บัญชีที่ชื่อต้นซ้ำกันเป็น "ชื่อ นามสกุล" (ผู้ใช้แจ้งชื่อจริงในแชทแล้ว ไม่บันทึกในไฟล์นี้)
แล้วแจ้งทั้งสองคนให้ล็อกอินด้วยชื่อใหม่ (หรือพิมพ์ชื่อต้นแล้วเลือกนามสกุล)
