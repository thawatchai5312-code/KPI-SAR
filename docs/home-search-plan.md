# แผน: ช่องค้นหาในหน้าแรก (ชื่อตัวชี้วัด / ผู้รับผิดชอบ)

สถานะ: **แผน รอผู้ใช้สั่ง "เริ่มได้"** · แก้เฉพาะหน้าแรก (`src/Index.html`) ไม่แตะเซิร์ฟเวอร์ · ขึ้นลิงก์ทดสอบก่อน แล้วผู้ใช้สั่งขึ้นหลัก

## 1. ตำแหน่ง
- แถบบนสุดของฝั่งขวา (`#kpi-list-area`)
  - **ตาราง**: แถวเดียวกับ "📋 ตาราง · แสดง N ตัวชี้วัด" และปุ่มแสดง/ซ่อนคอลัมน์ (`.tbl-toolbar`)
  - **การ์ด**: แถวบนสุดเหนือรายการ (แถบเดียวกับตัวแบ่งหน้า "แสดง 1–10 จาก N")
- ช่อง `🔍 ค้นหาชื่อตัวชี้วัด / ผู้รับผิดชอบ…` + ปุ่ม ✕ ล้าง (แสดงเมื่อมีคำค้น)
- จอโทรศัพท์: ช่องเต็มความกว้าง ขึ้นบรรทัดของตัวเองเหนือปุ่มคอลัมน์

## 2. การทำงาน
- ค้นแบบเดียวกับหน้าติดตามงาน: ไม่สนตัวพิมพ์เล็ก/ใหญ่ ตัดช่องว่างหัวท้าย · หลายคำคั่นช่องว่าง = ต้องเจอครบทุกคำ (AND)
- ช่องที่ค้น: ชื่อตัวชี้วัด + ผู้รับผิดชอบ + หน่วยงาน (ผู้ใช้เลือก)
- **ผังรายการซ้ายกรองตามด้วย** (หมวด/จำนวนตรงกับฝั่งขวา — ผู้ใช้เลือก) · กรอง **ร่วมกับ** ตัวกรองเดิม (มุมมอง รพ./QA/หน่วยงาน · ขอบเขต ของฉัน/หน่วยของฉัน/ทั้งหมด · สถานะ 3 สี) — ใส่เงื่อนไขใน `getOrderedKpis` ที่เดียว (หน้าสรุปรายงาน `forReport` ไม่ใช้คำค้นนี้)
- พิมพ์แล้วรอ ~0.3 วินาทีค่อยวาดใหม่ (กันตารางวาดซ้ำทุกตัวอักษร) · กลับไปหน้าแรกของรายการ (การ์ด) · ตารางยังวาดทีละชุดเหมือนเดิม
- ไม่พบ = "ไม่พบตัวชี้วัดที่ตรงกับ "…"" + ปุ่มล้างคำค้น
- ป้ายในแถบบอกว่ากำลังกรองอยู่ เช่น "แสดง 12 ตัวชี้วัด · ตามคำค้นหา"
- คำค้นคงอยู่เมื่อสลับการ์ด/ตาราง · สลับมุมมอง/ขอบเขต · อัปเดตอัตโนมัติทุก 10 วิ · **เปลี่ยนปีงบ = คงคำค้นไว้** (ผู้ใช้เลือก) · ออกจากระบบ = ล้าง (ไม่จำข้ามการล็อกอิน)
- ระหว่างแก้ไขตัวชี้วัด (การ์ด/แถวที่เปิดแก้ค้าง): ใช้ `guardUnsaved` แบบตัวกรองเดิม — เปลี่ยนคำค้นขณะมีงานค้าง ถามก่อนทิ้ง 
- `goToKpi` (กดจากหน้าติดตามงาน/ที่อื่น) ล้างคำค้นเมื่อตัวที่ต้องการถูกกรองหาย (ใช้กลไก `relisted` เดิม)

## 3. ไม่แตะ
- หน้าติดตามงาน · สรุปรายงาน · เซิร์ฟเวอร์ · การแก้ไข/บันทึก · ระบบสอน (ไม่เพิ่มขั้นสอน เว้นแต่ผู้ใช้สั่ง)

## 4. เทสต์ (`tests/ui76.js` ใหม่)
- ตาราง + การ์ด: พิมพ์ชื่อบางส่วน → เหลือเฉพาะที่ตรง · พิมพ์ชื่อผู้รับผิดชอบ → เหลือของคนนั้น · หลายคำ AND · ✕ ล้าง → กลับครบ
- ใช้ร่วมกับขอบเขต/สถานะ · คงคำค้นเมื่อสลับการ์ด/ตาราง · อัปเดตอัตโนมัติไม่ล้างคำค้น
- จอโทรศัพท์ไม่ล้น · ดูภาพหน้าจอใน `tests/out/`
- รันเทสต์หน้าแรกเดิมที่เกี่ยวข้อง (ตาราง/การ์ด/goToKpi) ซ้ำ
