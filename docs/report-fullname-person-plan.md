### ปัจจุบัน
`prMainTables(kpis, landscape)` ใน `src/Index.html` (~บรรทัด 5069) สร้าง 2 ตาราง:

### วิเคราะห์ปัญหาความสูงแถว
- ความยาวชื่อตัวชี้วัด (นับตัวอักษรที่กินที่ ไม่นับสระบน/ล่าง วรรณยุกต์) ในข้อมูลทดสอบ 311 ตัว:
  มัธยฐาน 45 · p75 57 · p90 79 · p99 143 · ยาวสุด 166 — **ยาวเกิน 40 ตัว 183 ตัว** (ถูกตัดในแนวนอน) และ **เกิน 18 ตัว 306 ตัว** (แนวตั้งแทบทุกตัวถูกตัด)
- **ช่อง "สรุป" ทำให้ทุกแถวสูง 2 บรรทัดอยู่แล้ว** (ตัวเลข + `<br>` + วิธีสรุป) → ชื่อที่ตัดเป็น ≤ 2 บรรทัด **ไม่ทำให้แถวสูงขึ้นเลย**
- ถ้าปล่อยชื่อเต็มในความกว้างเดิม: แนวนอน 21% ≈ 30 ตัว/บรรทัด → ชื่อยาวสุดกิน 6 บรรทัด · แนวตั้ง 15% ≈ 17 ตัว/บรรทัด → ยาวสุดกิน ~10 บรรทัด (แถวสูงมาก ตารางยาวขึ้นหลายหน้า)
- ขยายคอลัมน์ชื่อได้โดยลดช่องเดือน แต่ช่องเดือนเป็น `nowrap` ตัวเลขต้องพอดี: ค่าสูงสุดที่พิมพ์คือทศนิยม 2 ตำแหน่ง (`prNum`) เช่น `1234.56` (7 ตัว) → แนวนอน 10.5pt ต้องการช่อง ≈ 13–14 มม. = ~5% ของความกว้างกระดาษ (≈ 277 มม.) · แนวตั้ง 9pt ≈ 10.5–11 มม. = ~5.5% (≈ 190 มม.) — **ลดต่ำกว่านี้ตัวเลขล้นช่อง**

## (ข) KPI รายบุคคล → ตั้ง "2. เนื้อหาที่จะพิมพ์" ให้อัตโนมัติ · ล้าง → คืนค่าเดิม

### ปัจจุบัน
- ตัวเลือกเนื้อหาอยู่ใน `rpt.opts` (ค่าตั้งต้น `RPT_DEFAULT_OPTS = { table: true, chart: true, detail: true, source: false, owner: true }`) — ช่องติ๊ก `rp-opt-<key>` (`rptControlsHtml`) ตั้งค่าจาก `rpt.opts` ใน `rptSync(p)`
  - `table` = "ตารางตัวชี้วัด (เป้าหมาย ผล 5 ปี ผลรายเดือน)" — ตัวเดียวคุมทั้งตาราง 5 ปีและตารางรายเดือน (`prMainTables`)
  - `chart` = กราฟ + ตารางรายเดือนรายตัว · `detail` = รายละเอียด/การวิเคราะห์ · `source` = ที่มา/สูตร · `owner` = ผู้รับผิดชอบ
- ติ๊กเอง → `rptSetOpt` → `rptChanged` → `rptSaveSoon()` **จำค่าไว้ที่เซิร์ฟเวอร์** (`saveReportPrefs`: orient/opts/unchecked)
- KPI รายบุคคล (head ขึ้นไป, `rptCanPerson`): `rptPersonCommit` → `rptPersonLoad(name, silent)` (สำเร็จ = `rpt.personData` แล้ว `rptSync('rp')` + `rptRenderPreview`) · ล้าง = `rptPersonClear()` · ดึงใหม่เงียบ ๆ เมื่อมีคนแก้ = `rptPersonRefreshSoon` → `rptPersonLoad(rpt.person, true)` · ออกจากระบบ = `rptReset()`

### ข้อตกลงที่ใช้ในแผน (ผู้ใช้ยืนยัน/เปลี่ยนได้ก่อนเริ่ม)
1. เลือกบุคคล → `rpt.opts = { table: true, chart: false, detail: false, source: false, owner: false }` (เหลือแค่ "ตารางตัวชี้วัด (เป้าหมาย ผล 5 ปี ผลรายเดือน)")
2. **"เอาออก" = เอาติ๊กออก** (ช่องอื่นยังอยู่ ผู้ใช้ติ๊กเพิ่มเองได้ระหว่างดูรายบุคคล) — ไม่ซ่อน/ไม่ปิดช่อง
3. **"คืนค่าตั้งต้นเดิม" = ค่าที่ผู้ใช้ตั้งไว้ก่อนเลือกบุคคล** (ค่าที่จำไว้ของบัญชีนั้น ซึ่งปกติ = `RPT_DEFAULT_OPTS` ถ้าไม่เคยเปลี่ยน) — ไม่ใช่บังคับกลับ `RPT_DEFAULT_OPTS` ทุกครั้ง
4. การติ๊กระหว่างอยู่ในโหมดรายบุคคล **ไม่จำค่า** (ไม่ส่ง `saveReportPrefs` ด้วย `opts` ของโหมดรายบุคคล) และหายไปเมื่อกดล้าง
5. แนวกระดาษ / หมวดที่ติ๊ก ไม่เกี่ยว — คงพฤติกรรมเดิม

### การเปลี่ยนแปลงโค้ด (`src/Index.html` ส่วน "สรุปรายงาน / Export PDF")
1. ค่าคงที่ใหม่ `RPT_PERSON_OPTS = { table: true, chart: false, detail: false, source: false, owner: false }` และฟิลด์ใหม่ใน `rpt`: `optsBeforePerson: null`
2. ฟังก์ชันใหม่ `rptPersonOptsOn()`: ถ้า `rpt.optsBeforePerson === null` → `rpt.optsBeforePerson = Object.assign({}, rpt.opts)` แล้ว `rpt.opts = Object.assign({}, RPT_PERSON_OPTS)`
   - เรียกใน `rptPersonLoad` **เฉพาะตอนไม่ silent** (ก่อน `getKpisOfPerson` หรือตอนสำเร็จ — แนะนำตอนเริ่มโหลด เพื่อให้ช่องติ๊กเปลี่ยนทันที; ถ้าโหลดล้มเหลว `rptPersonClear` จะคืนค่าให้เอง)
   - เปลี่ยนจากคน A เป็นคน B: `optsBeforePerson` มีอยู่แล้ว → **ไม่เก็บซ้ำ และไม่ตั้ง preset ทับ** (ค่าที่ผู้ใช้ติ๊กเพิ่มระหว่างดู A คงอยู่ต่อกับ B) · ดึงใหม่แบบ silent ไม่แตะ `opts`
   - `rptOpenPage` ที่เรียก `rptPersonLoad(rpt.person)` ใหม่ (เปลี่ยนปีงบแล้วกลับมา) → `optsBeforePerson` มีอยู่แล้ว ไม่ทับ
3. ฟังก์ชันใหม่ `rptPersonOptsOff()`: ถ้า `rpt.optsBeforePerson` ไม่ใช่ null → `rpt.opts = rpt.optsBeforePerson; rpt.optsBeforePerson = null`
   - เรียกใน `rptPersonClear()` ก่อน `rptSync('rp')` (ครอบคลุมทั้งกด ✕ ล้าง, ลบข้อความในช่องแล้ว Enter, และโหลดล้มเหลว)
4. ไม่จำค่าโหมดรายบุคคล: ใน `rptSaveSoon()` ส่ง `opts: rpt.optsBeforePerson || rpt.opts` (ระหว่างโหมดรายบุคคล ส่งค่าเดิมก่อนเลือกบุคคลแทน — การเปลี่ยนแนวกระดาษ/หมวดระหว่างนั้นยังจำได้ตามเดิม)
5. `rptReset()`: ตั้ง `rpt.optsBeforePerson = null` (ออกจากระบบ/ล็อกอินใหม่)
6. `rptApplyPrefs` (โหลดค่าที่จำไว้ครั้งแรกต่อการล็อกอิน) ไม่เปลี่ยน — ตอนนั้นยังไม่มีบุคคลที่เลือก
7. ข้อความ `rp-person-note` (ใน `rptPersonUi`) อาจต่อท้าย " · เนื้อหาที่จะพิมพ์ตั้งเป็นตารางตัวชี้วัดให้แล้ว (กด ✕ ล้าง เพื่อคืนค่าเดิม)" — **ทางเลือก** ผู้ตรวจแผนตัดสิน (ไม่ใส่ก็ได้)
8. ไม่แตะ: ชุดควบคุมอื่นที่ใช้ `rptControlsHtml(p)` ที่ไม่ใช่ `'rp'` (ช่องบุคคลมีเฉพาะ `'rp'`) · `buildPrintHtml` · เซิร์ฟเวอร์ `getKpisOfPerson` / `saveReportPrefs`

### กรณีขอบที่ต้องตรวจ
| สถานการณ์ | ผลที่ต้องได้ |
|---|---|
| ค่าเดิม = ค่าตั้งต้น → เลือก A | ติ๊กแค่ "ตารางตัวชี้วัด" · ตัวอย่างรายงานไม่มีกราฟ/รายละเอียด/ผู้รับผิดชอบ |
| ระหว่าง A ติ๊ก "กราฟ" เพิ่ม → กด ✕ ล้าง | กลับเป็นค่าเดิมก่อนเลือก A (ไม่มีผลของการติ๊กกราฟ) |
| ผู้ใช้เคยตั้งค่าเอง (เช่น ติ๊กที่มา, ไม่ติ๊กกราฟ) → เลือก A → ล้าง | กลับเป็นค่าที่ผู้ใช้ตั้งเอง |
| A → เปลี่ยนเป็น B (ไม่ล้าง) → ล้าง | ล้างแล้วได้ค่าก่อนเลือก A |
| ระหว่างโหมดรายบุคคล ไม่มี `saveReportPrefs` ที่ `opts` = ค่าโหมดรายบุคคล | ล็อกอินใหม่ได้ค่าเดิม |
| มีคนแก้ข้อมูล → ดึงใหม่เงียบ ๆ | ช่องติ๊กไม่เปลี่ยน |
| ค้นชื่อแล้วเซิร์ฟเวอร์ตอบล้มเหลว | คืนค่าเดิม (ผ่าน `rptPersonClear`) |
| ออกจากระบบระหว่างโหมดรายบุคคล → ล็อกอินบัญชีอื่น | ไม่มีค่าค้างจากบัญชีก่อน |
| staff | ไม่มีช่องบุคคล — ไม่กระทบ |
